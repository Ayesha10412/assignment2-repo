# Fitness Website

This is a **Fitness Website** designed to offer users a comprehensive platform for accessing health and fitness content. It includes workout videos, fitness gadgets information, a BMI calculator, and an introduction to the professional training team.

## Features

- **Workout Videos**: Access over 500 free workout videos.
- **Fitness Gadgets Information**: Learn about tech gadgets for fitness tracking and health monitoring.
- **BMI Calculator**: Calculate your Body Mass Index to assess your health status.
- **Training Team Introduction**: Meet the professional trainers for guidance.
- **Responsive Design**: Optimized for all device types.

## Technologies Used

- **HTML**: For structuring the web content.
- **CSS**: For styling and layout design.


## Dependencies

This project is built with:
- Vanilla HTML, CSS, and JavaScript.
